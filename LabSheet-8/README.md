# Lab Sheet 8: Flutter SQLite Applications

This project covers Notes, Contacts, Expenses, To-Do, Registration/Login,
Form Validation, Student CRUD, and Product Inventory using SQLite.

## Run
1. Open this folder in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

The database is stored locally on the Android device.
This is a learning project, not production authentication.
