# LabSheet-9 — Question 10

**Original question:** Create a Flutter application to handle API errors (no internet connection or invalid response status code) and display an error message with a Retry button.

## Run
1. Open this folder as a Flutter project in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

Requires an internet connection. API examples use JSONPlaceholder or Fake Store API. The endpoint can be changed in `lib/main.dart`.
