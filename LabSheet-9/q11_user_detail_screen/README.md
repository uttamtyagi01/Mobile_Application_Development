# LabSheet-9 — Question 11

**Original question:** Create a Flutter application to display a list of users fetched from an API and open a Detail screen showing the complete details of the selected user.

## Run
1. Open this folder as a Flutter project in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

Requires an internet connection. API examples use JSONPlaceholder or Fake Store API. The endpoint can be changed in `lib/main.dart`.
