# LabSheet-9 — Question 15

**Original question:** Develop a Flutter Product Store Application that fetches a list of products (title, price, and image) from a public REST API, displays them in a GridView, and shows product details on a separate screen with a loading indicator and error handling.

## Run
1. Open this folder as a Flutter project in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

Requires an internet connection. API examples use JSONPlaceholder or Fake Store API. The endpoint can be changed in `lib/main.dart`.
