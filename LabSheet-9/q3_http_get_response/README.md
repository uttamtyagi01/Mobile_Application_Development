# LabSheet-9 — Question 3

**Original question:** Create a Flutter application to fetch data from a public REST API using http.get() and display the response body on the screen.

## Run
1. Open this folder as a Flutter project in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

Requires an internet connection. API examples use JSONPlaceholder or Fake Store API. The endpoint can be changed in `lib/main.dart`.
